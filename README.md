# Paradise Nursery

A React and Redux plant shop application featuring a landing page, product
catalogue, and shopping cart with quantity controls.

## Run locally

```bash
npm install
npm run dev
```

## Project files

- `src/App.jsx` - landing page and navigation
- `src/AboutUs.jsx` - company information
- `src/App.css` - application styling and landing-page background image
- `src/CartSlice.jsx` - Redux cart reducers
- `src/ProductList.jsx` - product listing
- `src/CartItem.jsx` - shopping cart
